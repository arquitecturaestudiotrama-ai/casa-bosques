# Casa Bosques · DFS Studio

Sitio de presentación de la vivienda en Barrio Bosques, Pinamar. Proyecto de DFS Studio Arq & Design.

Es un sitio estático: `index.html` y la carpeta `img/`. No necesita instalación ni compilación.

## Contenido

- Exteriores
- Planta baja
- Cocina, comedor y living
- Galería con parrilla
- Dormitorio principal
- Alternativa: garaje cerrado con portón y revestimiento en acero corten, con su planta

## Publicar en Vercel

1. Subí esta carpeta a un repositorio de GitHub.
2. En Vercel: **Add New → Project**, elegí el repositorio.
3. Framework Preset: **Other**. Dejá vacíos el Build Command y el Output Directory.
4. **Deploy**.

Cada cambio que subas a la rama `main` se publica solo.
